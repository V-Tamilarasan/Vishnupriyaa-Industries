Live Summary
🌐 Access Data on Any Desktop

This app stores data in your browser's localStorage — it's tied to this browser on this device. To access it on another desktop, use the Export/Import backup below.

📤 Option 1: Export Backup

Download a .json file with all your data. Open it on another PC to import.

📥 Option 2: Import Backup

Load a previously exported .json file to restore or migrate data.

☁ Option 3: Cloud Hosting

Host these 3 files (index.html, script.js, style.css) on:

  • Google Drive with apps.diagrams.net or similar
  • GitHub Pages (free, public URL)
  • Netlify Drop — drag & drop, instant URL
  • Local network — serve with VS Code Live Server
💡 Best practice: Export a backup every week. The .json file contains all materials, workers, orders, finished goods and sales — load it on any browser to continue working.
⚠ Danger Zone

This will permanently erase ALL data — materials, workers, orders, bills, and finished goods. This cannot be undone.
